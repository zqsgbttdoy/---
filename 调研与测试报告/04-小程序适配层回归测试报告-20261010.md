## 三、失败/阻塞项明细（后端「新增上线契约」组）

以下 9 项在 `qaAcceptance*` 契约用例中失败，属**此前生产上线评估任务固化的上线阻塞证据**（对应报告见《生产环境上线风险评估报告.md》）。本次改动未触碰任何后端源码，227 项既有回归全绿可交叉印证。

| # | 用例 | 现象 |
| --- | --- | --- |
| 1 | qaAcceptanceDirectoryRejectsOtherProject | 跨项目目录访问预期 403，实际 200 |
| 2 | qaAcceptanceNoticesAndContactsCannotSkipWorkflow | 通知单/联系单创建即 verified 未被拒绝 |
| 3 | qaAcceptanceRevokedAdminCannotManageUsers | 撤权 admin 仍可管理系统用户 |
| 4-7 | qaAcceptanceSafety*（4 项） | 安全日志审批流（草稿直批/提交留痕/正文不可变/审核权）未按预期拦截 |
| 8 | qaAcceptanceDisabledAdminCannotReactivateSelf | 已停用管理员可自助重新激活 |
| 9 | qaAcceptanceJwtTemplatePlaceholderMustFail | 公开模板占位 JWT 密钥未触发生产启动校验失败 |

> 这些失败不影响小程序适配层的验收结论，但在完成真实生产上线前必须逐项闭环。

## 四、执行中发现并修复的环境问题

| 问题 | 根因 | 处置 |
| --- | --- | --- |
| 第一次 `--regression` 后端未产出任何用例（tests=0） | `target\maven-status` 旧状态缓存 `inputFiles.lst` 在中文路径下损坏，maven-compiler-plugin 读取报错 | 删除可再生的 `target\maven-status` 缓存目录后重跑，242 项用例正常执行 |
| 本机 8080 端口被占用导致后端无法启动 | 另一无关项目（TIS 巡检系统）常驻 8080 | 未动第三方进程；监理后端改放 8090（`--server.port=8090`），静态代理 8091 通过 `E2E_BACKEND_PORT=8090` 转发，小程序侧地址（8091）不变。该场景已写入 README 排查指引 |
