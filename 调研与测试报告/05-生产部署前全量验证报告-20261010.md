## 四、部署文档一致性审查结果

### 🔴 A 级：按文档操作会直接失败或引入安全回退

| # | 不一致项 | 文档位置 | 实际实现 | 后果 |
| --- | --- | --- | --- | --- |
| A1 | **`APP_UPLOAD_SIGNING_SECRET` 在四份文档中完全缺失** | DEPLOYMENT.md 环境变量表（L155-161）与三处示例、ALIYUN_DEPLOYMENT.md、PRODUCTION_CHECKLIST.md「必填环境变量齐全」条目、OPS_HANDOVER.md 均未提及 | `supervision.env.example` 列为【必填 8/8】；`application-prod.yml` 无默认值；`ProductionSafetyValidator.validateUploadSigningSecret` 强制校验（≥32 字符、不得含占位符、不得复用 JWT 密钥） | 按文档准备环境变量 → 生产启动必然被快速失败拦截（好消息是响亮失败，但文档链路断裂，运维无从知道要加哪个变量） |
| A2 | **附件「/api/uploads/ alias 直出」口径过时，与加固后的实现矛盾** | DEPLOYMENT.md L166（要求与 nginx alias 路径一致）、ALIYUN_DEPLOYMENT.md L339（`location ^~ /api/uploads/` → alias）、OPS_HANDOVER.md L214-216（按 alias 排查附件恢复）、PRODUCTION_CHECKLIST.md 冒烟项「返回 URL …且可访问」 | `deploy/nginx-supervision.conf` 现版已将 `/api/uploads/`、`/uploads/` 一律 `return 403`，注释明确「原路径只作存库标识；经 `/api/files/access` 签发受控链接，`/api/files/content` 再验权限」（AttachmentAccessService） | 运维按文档配置 alias 直出或验收「URL 可访问」，等于**手工重新引入匿名直出附件漏洞**（与既有上线契约关注点直接冲突） |

| # | 不一致项 | 位置 | 实际情况 |

### ✅ 核对一致项

- 敏感变量清单（JWT/数据库/CORS/重置密码）命名与注入方式：env.example ↔ application-prod.yml ↔ 校验器三方一致；
- `supervision.service` 的 EnvironmentFile/WorkingDirectory/jar 名（`supervision-site-management-1.0.0.jar`，产物已核实在 target\）一致；
- nginx 登录限频、安全响应头、`client_max_body_size 100m` 与后端 100MB 上限一致；
- prod profile `ddl-auto=validate`、show-sql 关闭、Druid 池参数与文档描述一致。

## 五、上线标准结论

**当前不满足生产上线标准**，阻塞项归三类：

1. **业务契约**：9 项新增上线契约失败（安全日志/通知/联系单审批闭环、越权隔离、撤权失效、占位 JWT 校验），需后端修复专项，与小程序层无关（既有回归 227/227 + 上一轮 227/227 双重交叉验证零回退）。
2. **部署文档**：A1/A2 两项 A 级不一致必须先修订，否则按文档部署会「启动失败」或「人为恢复匿名直出漏洞」。
3. **未验证面**：真实 MySQL 迁移演练（B1/B2 相关）、真实 Nginx 环境、微信真机（模拟器 50/50 + 冒烟 16/16 已覆盖逻辑与接口，不替代真机验收）。

## 六、本地启动与真机预览指南

详见 [`补后端/miniprogram/README.md`](../补后端/miniprogram/README.md)（零基础版，含 ✅/❌ 确认步骤）。核心路径：

1. 两条命令起服务（本机 8080 若被其他项目占用改用 8090，README 有排查指引）：
   - `java -jar 补后端\backend\target\supervision-site-management-1.0.0.jar --spring.profiles.active=e2e --server.port=8090`
   - `$env:E2E_BACKEND_PORT="8090"; node e2e-static-server.js`
2. 微信开发者工具 → 导入 `补后端\miniprogram` → AppID 选「测试号」→ 详情·本地设置勾选「不校验合法域名」。
3. 工具内登录 `admin / 123456`（仅限 e2e 演示库；生产部署必须先改默认管理员密码）。
4. 「预览」扫码即上真机；真机使用手机热点时无法访问 127.0.0.1，需在同一 Wi-Fi 下把 config.js 临时改为电脑局域网 IP。
