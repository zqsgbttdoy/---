模块采用经典四层分层结构：`controller` 暴露 `/api/**` REST 接口，`service` 承载业务逻辑，`repository` 继承 `JpaRepository` 访问 MySQL，`entity` 为 JPA 实体；`dto` 与 `common` 作为请求/响应契约。

- 入口：`SupervisionApplication` 通过 `@SpringBootApplication` 扫描 `com.supervision` 包。
- 配置层：`config/WebMvcConfig` 注册静态资源映射与全局拦截器；`CorsConfig` 放行跨域；`PasswordConfig` 注入 BCrypt。
- 认证链路：`AuthInterceptor` 在 `preHandle` 中解析 `Authorization: Bearer <token>`，调用 `JwtUtil` 签发/校验 JWT，并将当前用户写入 `AuthContext`（ThreadLocal），`afterCompletion` 清理上下文；`WebMvcConfig` 将 `/auth/login`、`/uploads/**`、`/error` 排除在拦截之外。
- 数据源：`application.yml` 指定 Druid 连接池 + Hibernate DDL `update`，默认端口 8080、context-path `/api`。
- 异常处理：`exception/GlobalExceptionHandler` 统一捕获 `BusinessException` 并返回 `ApiResponse`。
- 依赖方向：controller → service → repository → entity，工具类 `util/JwtUtil` 被 interceptor/service 共用，无循环依赖。
