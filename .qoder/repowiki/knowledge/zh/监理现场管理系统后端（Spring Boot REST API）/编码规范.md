- 所有实体继承 `BaseEntity`，通过 `@PrePersist` / `@PreUpdate` 自动填充 `createTime` / `updateTime`，并使用 Lombok `@Getter @Setter @NoArgsConstructor`。
- Controller 方法统一返回泛型 `ApiResponse<T>`，并通过 `@AllArgsConstructor` 构造注入 Service。
- DTO 与 Entity 一一对应，按功能域分目录存放（如 `DailyInspectionDTO` 对应 `DailyInspection`），避免混用。
- Repository 仅继承 `JpaRepository<Entity, Long>`，不手写 SQL，复杂查询通过方法名派生或 `@Query`。
- 可配置项集中放在 `application.yml` 的 `app.*` 命名空间下，并通过 `${VAR:default}` 形式支持环境变量覆盖。
